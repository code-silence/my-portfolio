## Getting Started

### Requirements

Make sure Flutter is installed:

```bash
flutter --version
```

Then clone the repository:

```bash
git clone https://github.com/code-silence/portfolio-code-silence.git
```

Navigate into the project:

```bash
cd portfolio_code_silence
```

Install dependencies:

```bash
flutter pub get
```

Run the portfolio in Chrome:

```bash
flutter run -d chrome
```

## Build for Web

To create a production web build:

```bash
flutter build web
```

The generated website will be available inside:

```text
build/web/
```

This folder can be deployed to a static hosting provider such as Netlify.
